Hazard stacking model

How universal Hazard Protection combines with a specific resistance has not been measured in game. Pick a model; the combined column is a comparison aid, not a verified number.

Units not yet available

An imperial and metric toggle is planned. It is not built because the game reports distance three different ways for one weapon: Range in feet, Damage Drop Off in yards, and Optimal Range with no unit at all. Converting a figure whose unit is unknown would produce a confidently wrong number, which is worse than showing the raw value.

Colour blind mode not yet available

Planned, and intended to match the modes the game itself offers so the colours carry over rather than being a separate scheme. Blocked on capturing the in-game accessibility settings — the correct palette is whichever one Ubisoft uses, not whichever one is theoretically optimal.
